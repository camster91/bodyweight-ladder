# Compact exercise details

Release: 2026-10-26-compact-exercise-details

The expanded exercise previously repeated its name and step position, used a second colored panel, and displayed all progression steps immediately. It now keeps the existing header, prescription, cue, How to and Training settings. The progression uses one native Explore steps disclosure. It starts open when an exercise is expanded during a search, preserving access to matching variations. All step guides and Start here actions retain their original handlers.

Workout-menu sections use separators instead of colored panels. Session and progression algorithms are unchanged.

Automated and workout interaction tests remain skipped at the user's request. Visual review is separate from functional readiness.
