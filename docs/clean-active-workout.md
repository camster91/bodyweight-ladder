# Cleaner active workout

Once workout settings are deferred (recorded work, rest, a running hold, paused or finished), plan access moves into Options as Your plan & goals. Before starting, the plan summary remains visible. Pause stays directly available in the toolbar; How to and the main recording/start button stay on the exercise screen.

First-set guidance is one existing exercise cue without a repeated setup heading or control instructions. Next-exercise rest previews retain the explicit manual-start explanation. The counter uses a smaller responsive diameter and 48px minimum stepper targets.

Validation: inline JavaScript syntax and whitespace checks only. Application tests skipped at user request. No timer, recording, recovery or planning logic changed. Active-state runtime/physical-device appearance remains unverified; the user's unfinished workout is not changed for review.
