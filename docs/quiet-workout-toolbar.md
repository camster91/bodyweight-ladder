# Quiet workout toolbar

Release: 2026-10-26-quiet-workout-toolbar

Settings retains its text, gear, accessible name and save-attention indicator, with a quiet transparent surface across screens. Workout options uses an Options label and ellipsis instead of a competing settings-style icon and boxed button. Pause retains its outline and visible label in the workout toolbar.

The finished-workout action group has one full-width primary Done for today button. Add something else and Plan another workout remain direct actions below it with quiet styling. Their original handlers, labels and behavior remain unchanged.

Functional tests remain skipped at the user's request. The completion layout is a source-level presentation change and has not been exercised against the user's workout. No workout records are created for visual review.
