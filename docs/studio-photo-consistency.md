# Studio photo consistency

Release: 2026-10-26-studio-photo-consistency

Three older stock-photo mappings now use newly generated studio references: kettlebell swing, half-kneeling hip flexor stretch, and contract-relax hamstring stretch. These match the existing warm cream studio, cobalt kit, mint/coral accents, daylight and full-body framing. The hamstring photo was corrected from a yoga strap to a household towel to match the existing equipment description. It shows the stretch position, not the full contract-relax sequence.

Each image has a 360px thumbnail and 960px detail export in WebP, encoded without cropping. The app identifies all three as generated in technique guides. Original licensed assets and credits remain preserved. generated-sources.json records prompts, correction, reference and selected-source hashes. Technique review remains pending.

All photographic thumbnails share a neutral frame and border. Expanding a library row retains its thumbnail dimensions. Guide images use the same neutral background and retain their uncropped proportions. This does not make every source photograph stylistically identical; other legacy photos remain.

Functional tests remain skipped at the user's request. Image inspection is visual and does not constitute professional technique approval.
